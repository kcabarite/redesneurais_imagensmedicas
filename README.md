# Segmentação de dados e imagens com K-Means

Este projeto contém os exemplos de K-Means utilizados nas aulas.

## Instalação

No terminal do VS Code, Spyder, Anaconda Prompt ou PowerShell, execute:

```powershell
python -m pip install -r requirements.txt
```

## Arquivos

- `introKMeans06.py`: lê os arquivos `Painted_Data01.csv`,
  `Painted_Data02.csv` ou `Painted_Data03.csv` e agrupa os dados com K-Means.
- `introKMeans08.py`: lê a imagem `ImagemFuzzyCluster01.pgm`, transforma seus
  pixels em atributos e realiza a classificação com K-Means.

## Executar no VS Code

Instale as extensões **Python** e **Jupyter**, ambas publicadas pela Microsoft.
Depois, abra o arquivo `.py` e clique em **Run Cell** acima de cada célula
marcada com `#%%`.

Para executar todas as células pela janela interativa:

1. Pressione `Ctrl + Shift + P`.
2. Execute **Jupyter: Run Current File in Python Interactive Window**.

Os gráficos aparecerão na janela **Python Interactive**. Dê dois cliques em um
gráfico para abri-lo no visualizador ampliado.
